# Alisten

Alisten 的 Android/iOS Flutter 客户端，支持房间大厅、匿名成员、实时同步播放、队列与点赞、投票切歌、聊天、搜索与歌单、LRC 歌词、本机播放历史、设置和系统媒体控制。

## 检查更新

应用启动时向 GitHub 查询本仓库最新的正式版（不含草稿和预发布版），成功检查后 24 小时内不再自动查询；设置页“关于”中的“检查更新”可随时手动查询。请求不带任何凭据，但 GitHub 会因此看到设备的 IP 地址。发现新版本时弹出更新面板：Android 交给浏览器下载对应架构的安装包，没有对应架构的安装包时打开发布页；iOS 打开发布页。装了 GitHub App 的设备上，系统可能交给 GitHub App 打开这些链接。

Release 说明会以纯文本显示在应用的更新面板里，Markdown 格式和链接地址不会保留；发版时写的说明就是用户看到的更新内容。
